# Дизайн-система

Киберпанк без визуального шума: тёмный спокойный фон, неон только там, где он что-то сообщает.
Все значения — в `src/styles/tokens.css`, Tailwind читает их оттуда (`tailwind.config.ts`).

## Палитра

| Токен | Значение | Где используется |
|---|---|---|
| `--color-bg` | `#0a0e14` | фон страницы |
| `--color-surface` | `#0d1117` | карточки, панели |
| `--color-elevated` | `#141a23` | меню, всплывающие окна |
| `--color-line` / `--color-line-strong` | `#1f2733` / `#2d3848` | границы |
| `--color-fg` | `#e6edf3` | основной текст |
| `--color-fg-muted` | `#9aa7b8` | второстепенный текст |
| `--color-fg-subtle` | `#6f7c8e` | подписи, неактивное |
| `--color-accent` | `#00e5ff` (cyan) | главная кнопка, фокус, прогресс |
| `--color-magenta` | `#ff2e88` | редкие акценты: бейджи, новые достижения |
| `--color-success` / `warning` / `danger` | `#3ee88a` / `#ffc947` / `#ff5370` | статусы проверки |

**Правило дозировки.** Неон разрешён для кнопок, статусов, прогресса и фокуса. Заголовки, абзацы, фоны и рамки карточек — нейтральные. На одном экране не больше одной главной (cyan) кнопки.

Контраст текста на фоне: основной 15.6:1, второстепенный 7.1:1, подписи 4.6:1 (WCAG AA).

## Типографика

- **Текст:** Golos Text — спокойный гротеск с хорошей кириллицей, хорошо читается в длинных уроках.
- **Код:** JetBrains Mono — только для кода, примеров разметки и логотипа.
- Базовый размер 16px, межстрочный 1.6, ширина текста урока не больше 72 символов (`max-w-prose`).

## Движение

| Токен | Значение | Для чего |
|---|---|---|
| `--duration-fast` | 150 мс | hover, смена цвета |
| `--duration-base` | 200 мс | фокус, раскрытие |
| `--duration-slow` | 250 мс | заполнение прогресс-бара |

Разрешено: микро-переходы в ответ на действие пользователя (hover, focus, нажатие, обновление прогресса).

Запрещено: мерцание, глитч-эффекты на контенте, parallax, автопроигрывание видео и звука, бесконечные анимации. Утилиты `animate-pulse`, `animate-ping`, `animate-bounce` удалены из Tailwind; остался только `animate-spin` для индикатора загрузки.

При `prefers-reduced-motion: reduce` все длительности обнуляются.

## Тема

Только тёмная (`color-scheme: dark`). Светлая тема не планируется: если понадобится, достаточно переопределить переменные в `tokens.css` под селектором.

## Доступность

- Видимый фокус: двойное кольцо фон + cyan (`--focus-ring`) на любом интерактивном элементе.
- Состояния не передаются только цветом: у ошибок и успеха всегда есть текст.
- Прогресс-бары с `role="progressbar"` и подписью.
