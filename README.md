# CyberLearn

Учебный сайт в стиле киберпанк. Вёрстка сделана по макету Figma «CyberLearn — образовательный сайт (киберпанк)».

## Страницы

| Файл | Экран макета |
|---|---|
| `index.html` | 01 Вход, 03 Доступ запрещён (`index.html?error=1`) |
| `register.html` | 02 Регистрация |
| `check.html` | 04 Проверка доступа, 05 Доступ разрешён |
| `home.html` | 06 Главная |

Чистые HTML, CSS и JS, без сборки. Достаточно открыть `index.html` в браузере.

## Как войти

- Демо-аккаунт: **student_01** / **cyber123**
- Или зарегистрируйте новый аккаунт. Аккаунты хранятся только в этом браузере (localStorage). Это учебный проект, настоящего сервера нет.

Неверный пароль ведёт через экран проверки обратно на вход с ошибкой «Доступ запрещён». Верный пароль показывает «Доступ разрешён» и открывает главную. Кнопка с логином в шапке главной выполняет выход.

## Структура

```
css/style.css     — стили и токены цветов из макета
js/app.js         — логика входа, регистрации и проверки
assets/           — иконки
```
